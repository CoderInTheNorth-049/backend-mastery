# RFC template — copy into your assignment file

```markdown
# RFC-NNN: <one-line decision title>

**Author:** you · **Status:** draft · **Reviewers:** @team

## 1. Summary
Three sentences maximum. What is proposed and why now?

## 2. Context & problem statement
Facts that exist today (constraints, numbers, incidents). No solutions here.

## 3. Goals / Non-goals
- Goal 1 …
- Non-goal: explicitly OUT of scope …

## 4. Options considered

### Option A — <name>
Pros / Cons / Est. cost

### Option B — do nothing (always include)
…

### Option C — <the alternative you rejected>
…

## 5. Decision
One sentence, bolded.

## 6. Consequences
Positive… Negative… What becomes easier/harder?

## 7. Rollout plan
Shippable steps, each independently revertible.

## 8. Open questions
Explicit asks for reviewers.
```

## Reviewer checklist (score yourself)

| Criterion | Points |
|---|---|
| Summary decidable in 10 minutes | /4 |
| Context = pre-decision facts only, with numbers | /3 |
| ≥3 options; “do nothing” argued seriously | /4 |
| Decision single-sentence & unambiguous | /2 |
| Consequences name BOTH gains and costs | /3 |
| Rollout steps independently revertible | /3 |
| Open questions are specific asks to named reviewers | /1 |
