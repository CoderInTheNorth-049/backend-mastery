# Resource policy — free & open access only

**Rule:** every resource required by this curriculum is free to access: open-source project docs, public docs sites, GitHub-hosted books/guides, YouTube, and free tiers that don't require payment.

Paid items may appear only as `💰 optional` footnotes (e.g., books) — never as prerequisites, never gating any assignment or project.
