# The plain-language assignment template

Every rewritten `assignment.md` (phases 00–02 first, rest roll forward) follows this shape:

```md
# Assignment — <human title>

## The problem you're solving
2–4 sentences of STORY: why a real team needs this, what breaks without it.

## Your tasks
1. …concrete, numbered, each starting with a verb
2. …

## Definition of done
- [ ] observable outcomes (tests green / file exists / behavior demonstrated)

## Hints (open only when stuck)
<details> progressive hints </details>

## Going further (optional)
stretch ideas
```

Rules: contracts/APIs stay EXACTLY as before (specs are the law); keep every hint and rubric; just reorganize the top into story+tasks.
